# CryptoLabX

## Project Overview

CryptoLabX is a modular cryptography toolkit developed for learning and experimentation with classical and modern cryptographic algorithms. Week 1 establishes the project foundation by creating the folder structure, command-line interface, file analysis module, and logging system.
